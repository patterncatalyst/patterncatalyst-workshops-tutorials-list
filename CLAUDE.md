# CLAUDE.md — patterncatalyst-workshops-tutorials-list

Rules and conventions for working on this repo. Read before making changes.

## What this is

The hub / index site for the PatternCatalyst family: a Jekyll + GitHub Pages
site that card-grids our workshop and tutorial sites and carries three list
pages (Our Blogs, Blog Links, Books). Live at
<https://patterncatalyst.github.io/patterncatalyst-workshops-tutorials-list/>.

## House style

- Built in the `lgtm-jekyll` house style: Red Hat Display/Text/Mono fonts, the
  amber accent `--accent: #e8870c`. Do not change the accent or fonts.
- `assets/css/site.css` is shared house CSS; reuse its classes
  (`.hero`, `.section`, `.cards`, `.card`, `.chip`, styled `<table>`) rather
  than adding new ones.
- The site is data-driven. Pages iterate `_data/*.yml`; do not hand-write cards
  or rows.

## Layout convention

- **Listing / index pages use tables, not card grids** (Books, Our Blogs, Blog
  Links). The top-level site showcase on the home page stays a card grid.
- Tables use a `<colgroup>` with sensible column widths; link the title, put a
  short blurb as `<small>` beneath it, render tags as `.chip`s.

## How to update content

- **Add a workshop/tutorial site:** add an entry to `_data/sites.yml` under
  `entries:`. `group` must be one of the five in `groups:`. Set `site_url` to
  the live Pages URL or `null` (with a `note`) if there is no public site.
  Quote any `title`/`synopsis` containing a colon.
- **Add a book:** `_data/books.yml` is generated by `scripts/gen-books.py` but
  has since been hand-enriched (publisher URLs, `review_note`s). Prefer a manual
  edit, or re-run with `--enrich` (which only fills blanks). Do NOT re-run the
  base generator without `--enrich`; it would overwrite the curated data. Then
  place the book in a category in `_data/book_categories.yml` (by exact title);
  uncategorised books fall into an "Other" group.
- **Add a blog link:** add an entry to `_data/blog_links.yml` (schema at the top
  of the file). Verify the URL resolves (prefer the publisher/author's own
  domain, never Amazon/affiliate links).
- **Feature one of our posts:** add an entry to `_data/blogs.yml` pointing at the
  live post in the `patterncatalyst-blog` repo.

## Writing voice

Published copy (hero leads, blurbs) follows the `lgtm-professional-voice` rules:
no em-dash overuse (use commas, semicolons, colons, or separate sentences), no
contrived or AI-sounding phrasing. Run `lgtm-professional-voice`'s `scan.sh` on
changed files.

## Build, preview, publish

```bash
bundle install
bundle exec jekyll serve --baseurl ""   # preview at http://localhost:4000/
bundle exec jekyll build                # must exit 0, no Liquid/YAML errors
```

Pushing to `main` triggers `.github/workflows/pages.yml`, which builds with
`bundle exec jekyll build` and deploys to GitHub Pages. Confirm the Actions run
is green after a push.
